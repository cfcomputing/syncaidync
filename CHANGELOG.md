# Changelog

## 0.1.0

- Start and resume Claude Code, Codex, Pi, and Cursor Agent sessions in local terminals.
- See which sessions are blocked on you or ready for you in Your move, with snooze, sounds,
  and desktop notifications.
- Use new worktrees, existing folders, or scratch folders with Terminal, Files, Changes,
  and Session tools.
- Review changes with a change map, notes, and a suggested read-through.
- Open and review GitHub pull requests, and save a draft review.
- Close out a session and save takeaways for future sessions.
- Import Claude Code history, open GitHub links from sessions, and check for new releases.
- Build an optional macOS app with native notifications, a Dock badge, and a global hotkey.
